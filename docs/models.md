# Token Factory models

_Not generated yet._ This file is written by `scripts/discover_models.py` from `GET {NEBIUS_BASE_URL}/models`
once `NEBIUS_API_KEY` is available:

```bash
NEBIUS_API_KEY=... uv run --project api python scripts/discover_models.py
```

It lists every model the account can call and the Nemotron Nano / Super / Ultra (and safety) candidates for
`MODEL_FAST` / `MODEL_MID` / `MODEL_REASON` / `MODEL_SAFETY`. The default base URL
(`https://api.tokenfactory.nebius.com/v1/`) is unverified.
